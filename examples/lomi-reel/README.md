# Lomi showreel

A 30 s motion-design cut for Lomi, the open-source desktop workspace for terminal-driven development: a lime pill that floods the frame and splits it
into the real UI, kinetic type on the beat, a 3D dive through the workbench, a real commit and test run drawn as bars, fifteen agents around a hub,
a light and dark flip, and a lock-up where the pill lands as the dot of the i. 1920x1080 at 60 fps, 128 BPM (16 bars).

It was made in a Claude Code session with [HyperFrames](https://github.com/heygen-com/hyperframes), which renders HTML and GSAP scenes frame by frame,
not with the motion-designer skill. It sits here as another example of motion design made in Claude Code. No source is included in this repository.

Music and sound design: original, synthesized in code, no samples. The app captures, the commit and the test run on screen are real.
