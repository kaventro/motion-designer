# Oryn showreel

A 60 s motion-design cut for Oryn, the desktop file manager: real-UI choreography, variable-font type, true-3D keycaps, treemap and stat scenes,
and a lock-up where two panels morph into the two halves of the mark. 1920x1080 at 60 fps, 128 BPM (32 bars).

This one was **not made by the skill**. It was built by hand in a Claude Code session as a composition of HTML, CSS and one GSAP timeline, and
rendered to MP4. It sits here as a reference for how far the same kind of film can go. No source is included in this repository.

Music and sound design: original, synthesized in code (numpy), no samples.
